## 클라우드 서비스 비교

### 1. AWS EC2 (서울 리전 기준)

#### 일반 인스턴스 (K8s/Docker/MLflow용)

| 인스턴스 | 스펙 | On-Demand/hr | Spot/hr | 월 비용(Spot, 24/7) |
|---------|------|-------------|---------|-------------------|
| t3.micro | 2 vCPU / 1GB | $0.013 | $0.004 | ~$3 |
| t3.small | 2 vCPU / 2GB | $0.026 | $0.010 | ~$7 |
| t3.medium | 2 vCPU / 4GB | $0.052 | $0.021 | ~$15 |
| t3.large | 2 vCPU / 8GB | $0.104 | $0.037 | ~$27 |

#### GPU 인스턴스 (ML 학습용)

| 인스턴스 | GPU | On-Demand/hr | Spot/hr | 용도 |
|---------|-----|-------------|---------|------|
| g4dn.xlarge | T4 16GB | $0.647 | ~$0.18 | 가벼운 학습 |
| g5.xlarge | A10G 24GB | $1.237 | ~$0.35 | 중급 학습 |

#### Free Tier (2025.07.15 이후 가입 기준)

- 가입 시 $100 + 활동 완료 시 $100 = **최대 $200 크레딧**
- t3.medium 기준 약 3,846시간 = **약 5.3개월** 24/7 사용 가능
- 크레딧 초과 시 계정 일시정지 (과금 폭탄 없음)
- 기간: 6개월

#### 스토리지 (EBS, 서울 리전)

| 타입 | 비용 | 비고 |
|------|------|------|
| gp3 | $0.0912/GB/월 | gp2보다 20% 저렴, 성능 더 좋음. **항상 gp3 선택** |
| gp2 | $0.1140/GB/월 | 레거시 |

- 30GB gp3: ~$2.74/월
- 100GB gp3: ~$9.12/월

#### 참고사항
- 서울 리전은 US East 대비 약 25% 비쌈
- Spot 인스턴스는 60~67% 할인이지만 중간에 종료될 수 있음
- t3는 기본 "unlimited" 모드 → CPU 버스트 초과 시 추가 과금. Spot 사용 시 "standard" 모드로 변경 권장

## 카드는 있는데 AWS가 안 될 때

| 서비스 | 한국 체크카드 | 무료 혜택 |
|--------|-------------|----------|
| **네이버 클라우드** | O | 10만원 크레딧 + 1년 무료 서버 |
| **Oracle Cloud** | 가능 (Visa/MC) | **영구 무료** ARM 4코어 / 24GB RAM |
| **GCP** | 가능 (Visa/MC) | $300 크레딧 (90일) + e2-micro 영구 무료 |

### Oracle Cloud 영구 무료 특이사항
- ARM 4코어 / 24GB RAM → AWS t3.large보다 좋은 스펙을 **평생 무료**
- 200GB 블록 스토리지, 로드밸런서 1대 포함
- 단, 아시아 지역 가입 시 인증이 까다로울 수 있음

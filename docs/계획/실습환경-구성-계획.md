## 설치해야 할 도구

### 1단계: 기본 도구

```bash
# Docker Desktop (컨테이너 런타임)
brew install --cask docker

# Terraform (IaC)
brew install terraform

# kubectl (K8s CLI)
brew install kubectl

# kind (로컬 K8s 클러스터)
brew install kind
```

### 2단계: 가짜 AWS (LocalStack)

```bash
# LocalStack (로컬에서 AWS 서비스 에뮬레이션)
brew install localstack/tap/localstack-cli
pip install localstack

# 실행
localstack start
# → localhost:4566에 S3, EC2, IAM 등이 뜸
```

### 3단계: Python 환경

```bash
# MLflow + ML 라이브러리
pip install mlflow scikit-learn boto3
```

## 단계별 실습 환경 매핑

| 단계 | 클라우드 대신 사용할 것 | 비고 |
|------|----------------------|------|
| 01-terraform | **LocalStack** | provider endpoint를 localhost:4566으로 변경 |
| 02-kubernetes | **kind** | `kind create cluster --name ml-standard` |
| 03-gitops-argocd | **kind 클러스터 위에 ArgoCD** | 그대로 kubectl apply |
| 04-artifact-minio | **Docker Compose** (이미 세팅됨) | `docker compose up -d` |
| 05-experiment-mlflow | **로컬 pip** (이미 세팅됨) | `python train_example.py` |

## Terraform + LocalStack 연동 방법

`01-terraform/provider.tf`를 로컬 실습용으로 수정:

```hcl
provider "aws" {
  region                      = "ap-northeast-2"
  access_key                  = "test"
  secret_key                  = "test"
  skip_credentials_validation = true
  skip_metadata_api_check     = true
  skip_requesting_account_id  = true

  endpoints {
    s3  = "http://localhost:4566"
    ec2 = "http://localhost:4566"
    iam = "http://localhost:4566"
  }
}
```
